🛒 Amazon India: A Decade of Sales Analytics (2015–2025) 📈🇮🇳
📌 Project Overview

This project builds a comprehensive end-to-end E-Commerce Analytics Platform using 10 years of Amazon India transactional data (2015–2025).

The objective is to transform raw, messy e-commerce data (with 25% data quality issues) into a professional Business Intelligence solution with advanced analytics, SQL integration, and interactive dashboards.

This project demonstrates real-world data science, analytics engineering, and business intelligence skills suitable for a professional portfolio.

🎯 Problem Statement

Develop a complete analytics pipeline that includes:

🧹 Advanced Data Cleaning on messy real-world data
📊 20 Professional EDA Visualizations
🗄️ SQL Database Integration
📈 25–30 Interactive BI Dashboards (Power BI / Streamlit)
💡 Strategic Business Insights for decision-making
